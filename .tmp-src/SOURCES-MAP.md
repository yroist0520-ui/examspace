## 四六级（过级鸭 guojiya.cn，结构化整卷页最佳）
- URL 规律：`https://www.guojiya.cn/exam/{cet4|cet6}_{YYYY}_{MM}_{S}/answers?layout=step`
- 含：写作Directions+范文、听力1-25题干选项答案、选词填空文章+词库、长篇阅读段落、仔细阅读两篇、翻译中文+译文（**无听力原文**）
- 听力原文：词通英语 `https://www.wordcram.com.cn/tests/cet4/listening/{YYYY-MM}-{S}`、可可英语、懒笔记、微信逐题解析
- 已确认12月场次覆盖好；6月场次（2019-06/2021-06/2024-06/2025-06）过级鸭多无，需另找

## 考研英语一/二（yingyuzhenti.com，结构化逐题页最佳）
- 整卷页：`https://www.yingyuzhenti.com/papers/{YYYY}-english-{one|two}`
- 逐题型页：`.../{YYYY}-english-one/cloze|reading-text-1..4|new-type|translation|writing`（每页含原文+题干选项+答案+逐题解析）
- 备选：lazynote.cn/kaoyan（网页版+PDF/Word）、新东方 kaoyan.xdf.cn、yingyuzhenti.com/blog 答案汇总
- 题型：完形20 + 阅读A 20 + 新题型5 + 翻译5 + 写作2 = 52题；kind 用 cloze/reading/translation/writing
