## 2. 分阶段功能验收（浏览器实测）

### 第三阶段：真题库与在线阅读 ✅
- 首页 / 真题库多维筛选 / 试卷详情 / 阅读器全部可用
- 高亮三色标注与笔记、点词查词弹窗、阅读位置恢复、主题切换

### 第四阶段：考试、听力、阅读、翻译写作 ✅
- 练习中心选卷；作答 → 交卷 → 判分 → 成绩报告链路完整
- 错题重练精准圈题（单题 1/1 100%）；模拟考试倒计时递减（2:05:00 → 2:04:50）并到点自动交卷
- 答案/草稿刷新不丢（IndexedDB 持久化）；听力播放控件与原文同步；范文收藏与练习中心联动

### 第五阶段：查词、生词本、错题本、学习统计 ✅
- 生词本：阅读页点词入库（含来源语境）→ 复习三档推进记忆箱并持久化 → CSV 导出、搜索/标签/状态筛选、掌握与删除均正常
- 错题本：考试/题型/年份/未掌握四类筛选；展开原题 + 解析；标掌握/恢复双向；一键重做跳转单题练习
- 统计页：6 概览卡、近 14 天柱状图、分考试表现、七箱分布、最近成绩跳转成绩报告；首页小部件回归正常

### 第六阶段：设置、PWA、移动端、交付 ✅
- 设置页：三主题实时切换（纸白/米黄/夜间）、字号/行距/每日目标滑杆、开关持久化、
  JSON 导出触发下载、清空数据二次确认可安全取消；`/words` `/mistakes` 无回归
- PWA：生产构建注册 Service Worker；`/manifest.webmanifest`（含图标、standalone、快捷方式）、
  `/sw.js`、`/icon.svg` 均正常伺服；SPA 子路由在预览服务器直达正常；预览源控制台零错误
- 关键流程回归：首页 → 练习中心 → 练习作答 → 交卷 → 成绩报告（0/23，含错题重练入口）完整走通；
  阅读器直达 `/read/:id` 正常
- 移动端：底部五项导航 `md:hidden`、汉堡抽屉含全部入口、`scrollWidth == innerWidth` 无横向溢出、
  阅读器移动端「目录」抽屉存在；已在第六阶段升级为真实 Chrome 视口 E2E（见上方自动化门禁）

**全程浏览器控制台：仅 Vite HMR 与 React DevTools 提示，零 error / 零 warning。**

## 3. 已知限制

1. **移动端视口已自动化**：由 `npm run test:mobile` 真实 Chrome 视口覆盖
   （320–1280px 五档视口 × 全路由溢出矩阵 + md/lg 断点边界 + 移动交互）；
   尚未覆盖的场景：真机触感/软键盘弹出、横屏、iOS Safari 专有行为，建议真机抽测一次。
2. **离线 SW 行为未在断网环境实测**：Service Worker 已注册并伺服，
   断网回退逻辑经代码审查，建议部署 HTTPS 后用 DevTools Network→Offline 复验一次。
3. **PWA 安装提示**依赖 `beforeinstallprompt`，桌面 Chrome 需满足安装条件才出现条幅。
4. oxlint 17 条 `exhaustive-deps` 警告为既有模式（有意引用稳定值），未修复。
5. 双数据层（Dexie `examspace` + idb 规范化层 `examspace-db`）并存，
   运行时仅用 Dexie 层，规范化层待后续整合。
